## 2. 기능 요구사항

### 2.1 User (회원/인증)
- FR-U1: 사용자 이름(username, unique) / 이메일(unique) / 비밀번호로 회원가입
- FR-U2: username 또는 email + 비밀번호로 로그인, 인증 토큰 발급
- FR-U3: 로그인한 사용자의 정보 조회(닉네임, 실명, 프로필 이미지) — 프로필 화면 상단 노출용

### 2.2 Post (게시물)
- FR-P1: 이미지 + 캡션으로 게시물 작성 (오디오/설문/사람 태그/위치 태그는 Sprint 1 범위 밖)
- FR-P2: 로그인한 본인의 게시물 목록 조회 (프로필 그리드용, 페이지네이션)
- FR-P3: 본인 게시물 수 조회 (프로필 상단 "게시물" 카운트)

## 4. Sprint 1 범위 밖 (다음 스프린트 이후)

- 홈 피드, 좋아요, 댓글, 팔로우/팔로잉, 프로필 편집, 추천 사용자, 타인 프로필 조회
- 게시물 작성 부가 기능: 오디오 추가, 설문, 콜라보 게시물, 사람 태그하기, 위치 추가
- 공유 시트, 스토리, 릴스, 검색 탭

## 5. 비기능 요구사항

- 인증: JWT 기반, 로그인 필요한 API는 Bearer 토큰 필수
- 페이지네이션: 본인 게시물 목록 조회는 cursor 또는 offset 기반 페이지네이션 적용
- 이미지 업로드: MVP는 이미지 URL 문자열 저장(실제 파일 업로드/스토리지 연동은 범위 밖, mock 가능)
- 정렬: 본인 게시물 목록은 최신순(createdAt DESC) 기본
